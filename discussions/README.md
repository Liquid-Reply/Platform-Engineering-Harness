# Discussions

Open questions and the reasoning behind our answers. Settled, stable material belongs in `docs/`.

One file per question, named `NNNN-slug.md`, flat. `topic` and `status` live in the frontmatter; status is one of `open`, `converging`, `decided`, `parked`, `superseded`. We'll add folders if the flat list stops scaling.

**To open one:** copy `_template.md`, fill in the question, run the [`related-work`](../.agents/skills/related-work/SKILL.md) skill against it, open a PR. Fold review conclusions back into the document.

Claims about tooling age fast. Cite a source and date for anything load-bearing.
